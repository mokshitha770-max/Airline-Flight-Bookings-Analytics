# ✈️ Airline Flight Bookings Analytics

## Project Overview
This project focuses on analyzing airline flight booking data to understand booking trends, passenger behavior, revenue patterns, and flight performance.

The goal is to transform raw booking data into meaningful business insights using data analytics tools.

## Objectives
- Analyze airline booking trends.
- Understand passenger booking behavior.
- Identify popular routes and airlines.
- Analyze ticket prices and revenue.
- Evaluate flight and booking performance.

## Tools & Technologies
- SQL – Data querying and analysis
- Microsoft Excel – Data cleaning and analysis
- Power BI – Interactive dashboards and visualization

## Project Structure
- `Dataset/` – Raw airline booking data
- `SQL/` – SQL queries and analysis
- `Excel/` – Excel analysis
- `PowerBI/` – Power BI dashboard
- `Dashboard_Screenshots/` – Dashboard images
- `Documentation/` – Project documentation

## Key Business Questions
1. Which airlines receive the highest number of bookings?
2. Which routes are most popular?
3. What are the booking trends?
4. How does ticket price vary across airlines?
5. What is the distribution of booking statuses?
6. Which routes generate the highest revenue?
